# Piano Tuner AI Privacy Policy

This repository hosts the public privacy policy for the Piano Tuner AI Android app.

Public policy URL: [https://balazslapis.github.io/tunerai-privacy/](https://balazslapis.github.io/tunerai-privacy/)

The page documents the app's actual microphone processing, Firebase authentication and cloud sync, Bluetooth motor connection, storage, retention, and deletion practices.
